What changed

Public users register and authenticate by email one-time code. Department administrators configure programs, notification recipients, and retention. Staff see only their assigned programs.

Protection and deletion

Uploads are staged in private quarantine over TLS. A fresh isolated ClamAV execution inspects the complete file before it is copied into a program folder in the selected department container. Defender for Storage then scans that copy at rest. Authenticated Event Grid results must match the exact stored blob ETag before the broker releases a download.

Files are inaccessible at retention expiry; an hourly job removes expired payloads. A successful server-side download response deletes the stored payload; an interrupted transfer keeps it for retry. Server completion cannot prove that a user saved a durable local copy. Soft delete and versioning must remain disabled for immediate physical deletion; Azure policy may require a different records-management arrangement.

Enterprise security

Department and program authorisation is enforced in the API, not only the UI. OTPs are single-use, hashed, expire after ten minutes, allow five attempts, and have resend limits. Sessions last eight hours and are held only in browser memory. Storage denies public networking and shared keys. Managed identity authenticates Azure service calls. Scanner jobs have no inbound ingress; they still need outbound Azure access. No WAF or Application Gateway is provisioned.

JSON metadata and auth state use private blobs, avoiding another database. ClamAV inspection has a 2 GiB minus 1 byte limit; encrypted, over-limit, errored, and unconfirmed files are not released. Malware scanning is not vulnerability analysis or content classification. This is not a compliance certification.

Cost and operating model

SWA Free, an existing Basic registry, LRS storage, scale-to-zero broker, per-file scanner jobs, hourly short cleanup runs, and usage-based email minimise fixed costs. Defender is an explicit new paid requirement; chargeable scan volume is limited to department copies, with a configurable monthly cap. A cap can stop scanning, so files remain blocked rather than bypassing protection.

Operations

Rebuild scanner images regularly for fresh signatures, monitor failed jobs and pending scans, review staff memberships, and alert on Defender scan-cap exhaustion. ACS Email is a replaceable delivery integration: Microsoft lists retirement for September 30, 2028.
